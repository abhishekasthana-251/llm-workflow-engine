# # LLM Workflow Engine

A structured hands-on repository to learn and implement core concepts of LangChain, including LLMs, Chains, Runnables, Output Parsers, and Retrieval-Augmented Generation (RAG).


### 1. Clone the repository

```

git clone https://github.com/abhishekasthana-251/llm-workflow-engine.git
cd llm-workflow-engine
```
## 🧪 Example Use Case

This repository includes a basic Retrieval-Augmented Generation (RAG) pipeline:

- Load documents (PDF, CSV)
- Convert to embeddings
- Store in vector database (Chroma)
- Retrieve relevant chunks
- Generate answers using LLM
